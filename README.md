# Mission Control companion

This repository only holds the installers of the Mission Control companion app, published as
[releases](https://github.com/gmarchildon/mission-control-companion/releases). The app downloads its updates from here.
Its source code lives in the main Mission Control repository.

The companion runs in the tray on the streaming computer. It pairs with your Mission Control project using a short code,
and brings OBS, game data and log files into Mission Control, within permissions you set on that computer.

## Install

- **Windows:** download `Mission-Control-companion-Setup-<version>.exe` from the latest release. The installer isn't
  signed during the beta: Windows SmartScreen shows a warning; choose "More info", then "Run anyway".
- **Linux:** download `Mission-Control-companion-<version>.AppImage`, make it executable, and run it.

Then follow the code it shows to pair it with your project.
